# КЕЙС 32 "Обеспечение процесса защиты от утечек информации"

---

Обеспечение результативной безопасности информации ограниченного доступа.

Ожидаемый результат:
1. Определить виды угроз для информационной безопасности предприятия.
2. Построить систему DLP защиты информации с использованием технических средств и организационных мероприятий в виде блок-схемы.

Проект создан для демонстрации разработанной архитектуры и методики программной DLP-защиты путем симуляции работы сетевых устройств,
сетевых протоколов и процесса передачи данных в незашифрованном виде между устройствами.

Исходный код модуля DLP и файлы правил разместить в `.\src\dlp\`. Разработанный прототип DLP-агента устанавливается как атрибут класса `Endpoint` (`None` по умолчанию).
